# Code of Conduct

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. The full text is at that link and applies here as written.

The short version: be decent to people. Criticise code, not the person who wrote
it. Assume the other party is trying to help.

## Reporting

Report unacceptable behaviour to the maintainer through GitHub —
[@Xoviec](https://github.com/Xoviec) — by direct message or by opening an issue
if the matter is already public. Reports are handled privately, and the person
who reported is not named without their agreement.

This is a one-maintainer project, so there is no committee behind that: if the
problem is with the maintainer, the Contributor Covenant's own escalation advice
is the honest answer, and forking is always available.
